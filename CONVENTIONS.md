# Conventions

## Stack

- Python 3.10+, FastAPI, Pydantic v2, async/await
- SQLAlchemy 2.0, Repository pattern
- Ollama/llama-cpp, DI for models, caching, streaming
- React+TS+Vite, Tailwind, Axios, WebSocket

## Style

- Type hints, PEP 8, Google docstrings, black (100 chars)
- ESLint+Prettier for frontend

## Testing

- pytest, 80% coverage, Jest, unit+integration tests

## Security

- Input validation, rate limiting, CORS, .env for secrets

## Performance

- Async LLM, connection pooling, lazy loading, batch processing

## Git

- Feature branches, conventional commits, PR required
