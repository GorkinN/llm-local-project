# Code Generator

Generates code by sending a prompt directly to an Ollama model via the `/api/generate` endpoint. The model does not see Pi's tools, so it returns pure text code without attempting tool calls.

## When to use

Use this skill when:

- You need code generated by `qwen2.5-coder:14b-instruct` or another instruction-tuned model.
- The model does not support function calling.
- You want a clean code output without markdown wrappers or explanations.
- You want to isolate code generation from the main agent's context.

## Input

JSON object with the following fields:

| Field         | Required | Default                                                                                                                    | Description                                 |
| :------------ | :------- | :------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------ |
| `prompt`      | yes      | —                                                                                                                          | Task description for code generation.       |
| `model`       | no       | `qwen2.5-coder:14b-instruct`                                                                                               | Ollama model name.                          |
| `system`      | no       | `"You are a code generator. Output only code without explanations, without markdown wrappers, and without introductions."` | System prompt.                              |
| `temperature` | no       | `0.2`                                                                                                                      | Sampling temperature.                       |
| `max_tokens`  | no       | `8192`                                                                                                                     | Maximum tokens to generate (`num_predict`). |

## Usage

```bash
node node .pi/skills/code-generator/code_generator.js '{"prompt": "<requested-functionality>"}'
```

Accepts promt:

- `Write a Typescript function to read a JSON file with error handling`
- `Refactor function`

## Output

JSON object:

```json
{
  "success": true,
  "model": "qwen2.5-coder:14b-instruct",
  "code": "<generated code>",
  "tokens_generated": 123
}
```
