# Task Breaker Examples

## Example 1: Coding Task

**Input:**
```
Refactor the user authentication module to use OAuth2 and implement password reset functionality
```

**Expected Plan Structure:**
- Phase 1: Current State Analysis
- Phase 2: Requirements for OAuth2 implementation  
- Phase 3: Password Reset Flow Design
- Phase 4: Unit Testing Strategy
- Phase 5: Integration Planning
- Phase 6: Security Auditing Steps
- Phase 7: Documentation Updates

## Tips for Better Plans

1. **Be Specific**: The more details in the task description, the better the breakdown
2. **Include Constraints**: Mention time limits, budget, or quality requirements
3. **Specify Goals**: Clear success criteria help create focused sub-tasks
4. **Mention Dependencies**: Note what tools/teams are involved

---

## Output File Format

The generated plan will be saved as a Markdown file containing:

1. Task summary
2. Phase breakdown with complexity indicators
3. Dependencies between phases
4. Resources and prerequisites
5. Success criteria for each phase
6. Estimated timelines (optional, based on input)
7. Checklists for each sub-task

The plan can be converted to:
- Project management task lists
- Agile user stories
- Sprint planning items
